# PolicyRaj Website

## Files
- `index.html` – Main HTML (all pages/sections)
- `style.css` – All styles & responsive layout
- `script.js` – Interactivity (tabs, modal, form, scroll)
- `policyraj.png` – **Place your logo file here** (same folder)

## Setup in VS Code
1. Copy all 4 files into one folder (e.g. `policyraj-website/`)
2. Drop your `policyraj.png` logo into the same folder
3. Open with **Live Server** extension (right-click index.html → Open with Live Server)
4. Done!

## Sections Included
- Sticky navbar with mobile hamburger menu
- Hero with animated insurance cards
- Insurance quote forms (Health / Life / Motor / Travel / Home / Business)
- 12-card Services grid
- Why Choose Us
- About Sachin Kathuria
- Testimonials
- Contact form + contact details
- Footer with links
- WhatsApp floating button
- Get Quote modal popup
- Success toast notification
- Back-to-top button

## Customisation
- Colors: edit CSS variables at the top of `style.css` (`:root { ... }`)
- Phone/email: search and replace `9013976999` / `sachin@policyraj.in` in `index.html`
- Logo: replace `policyraj.png` with your image file
